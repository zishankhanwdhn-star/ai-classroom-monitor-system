 🚀 AI Classroom Monitor System

«🧠 Smart AI-powered classroom monitoring system using Computer Vision & Automation»

---

🌟 Overview

AI Classroom Monitor System ek intelligent surveillance system hai jo classroom activities ko monitor karta hai using AI (YOLOv8).
Ye system automatically detect karta hai events, snapshots leta hai aur alerts generate karta hai — fully automated.

---

✨ Key Features

- 🎥 Real-time Camera Monitoring
- 🤖 AI Object Detection (YOLOv8)
- 📸 Auto Capture & Snapshots
- 🚨 Alert Management System
- 🧠 Smart Database (SQLite)
- 🌐 Web Interface (Admin Panel + Login)
- 🔐 Secure Authentication System

---

🧰 Tech Stack

Layer| Technology
Backend| Python
AI Model| YOLOv8 (Ultralytics)
Database| SQLite
Frontend| HTML, CSS
Libraries| OpenCV, Flask, Ultralytics

💻 Setup (VS Code Friendly)

1️⃣ Open Project in VS Code

- Open VS Code
- Click File → Open Folder
- Select your project folder

---

2️⃣ Create Virtual Environment

python -m venv venv

---

3️⃣ Activate Environment

👉 Windows:

venv\Scripts\activate

---

4️⃣ Install Dependencies

pip install -r requirements.txt

---

▶️ Run the Project

👉 Recommended command:

py -3.11 app.py

👉 OR:

python app.py

---

🌐 Access Application

Open browser:

http://localhost:5000
